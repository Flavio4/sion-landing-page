# Sion Desarrollos — Landing Page

Landing page de Sion Desarrollos E.A.S, construida con React + Vite.

## Desarrollo

```bash
npm install
npm run dev
```

## Build de producción

```bash
npm run build
```

## Contenido

Toda la copy y los datos del sitio (servicios, contacto, historia, etc.) viven en `src/content/site.js` y `src/content/projects.js` — son la fuente única de verdad, extraída del formulario que completó el cliente. Actualizar ahí cuando llegue contenido nuevo.

Hay varios `TODO` marcados en esos archivos para datos/imágenes pendientes de confirmar con el cliente (ver comentarios en el código).

Las imágenes reales del cliente (logo, banner, fotos de proyectos) van en `public/images`.
